# Guía de campo Personal · Investigar, conectar, convertir
Material didáctico original · BuscaClientes · edición 0.1

## Paso 1. Tu cliente ideal no es «cualquier negocio»
Completa antes de consultar:
| Pregunta | Respuesta |
|---|---|
| ¿Qué problema concreto resuelvo? | |
| ¿Quién reconoce o padece ese problema? | |
| ¿En qué ciudades puedo atenderlo de verdad? | |
| ¿Qué señal pública sugeriría pertinencia? | |
| ¿Qué indicio demostraría que NO conviene escribir? | |
| ¿Cómo mediré si mi oferta ayuda? | |

El objetivo no es maximizar nombres recolectados, sino **aumentar pertinencia comprobable**. No confundas ausencia de web en OSM con una debilidad real del negocio.

## Paso 2. Prueba de pertinencia de 60 segundos
Para cada negocio: (a) nombre y lugar; (b) actividad real observada; (c) fuente y fecha; (d) canal publicado apto para consultas comerciales; (e) hipótesis concreta que pueda confirmarse sin invadir privacidad; (f) siguiente acción pequeña y reversible.

**Etiquetas de evidencia:** COMPROBADO (fuente directa consultada), OBSERVADO (directorio público), HIPÓTESIS (inferencia, no hecho) y DESCONOCIDO. Nunca conviertas una hipótesis en un diagnóstico presentado como verdadero.

## Paso 3. Tres mensajes de apertura originales (personalizar, no automatizar a escala)
**A. Servicio profesional, español:**

> Hola, [nombre del negocio]. Vi que trabajan en [actividad verificable] en [zona]. Ayudo a [tipo de negocio] a [resultado concreto que realmente ofrezco]. ¿Tiene sentido hablar brevemente para entender si eso es relevante para ustedes? Si no es oportuno, no volveré a escribirles. Gracias, [firma].

**B. Comercio pequeño, español:**

> Buen día. Conocí su tienda por [fuente pública]. Trabajo con negocios como el suyo en [área específica]. No conozco todavía sus prioridades, por eso prefiero preguntar antes de proponer algo: ¿están evaluando mejoras en [tema]? Si no corresponde, gracias igualmente.

**C. Contexto internacional, inglés (uso individual):**

> Hello [business/team], I found your public business profile while researching [city/sector]. I help [specific audience] with [truthful service]. Would a short introduction be useful, or is there a better public channel for enquiries? No follow-up if this is not relevant. Regards, [signature].

**Control antes de enviar:** ¿Hay un motivo concreto, canal apropiado, afirmaciones verificables, identificación del remitente, y un modo simple de rechazar contactos posteriores? No emplear datos privados, información sensible o declaraciones de relaciones que no existen.

## Paso 4. Seguimiento prudente
| Estado | Acción posible | Condición para avanzar |
|---|---|---|
| Nuevo | Verificar pertinencia y canal | Evidencia suficiente |
| Contactado | Esperar respuesta | Registrar fecha, no suponer interés |
| Seguimiento | Un recordatorio breve, si procede | No existe rechazo ni prohibición |
| Calificado | Especificar necesidades y límites | La contraparte expresó interés |
| Ganado | Acordar alcance y condiciones | Compromiso real documentado |
| Descartado | Cerrar, no insistir | No relevante, petición de no contacto u otra razón |

**Seguimiento de cortesía:**

> Hola, retomo una sola vez mi consulta sobre [tema], por si coincidía con una prioridad de ustedes. Si no es oportuno, no hace falta responder y daré el asunto por cerrado. Gracias.

## Revisión semanal de 15 minutos
Cuenta SOLO eventos que sucedieron: contactos elegidos, mensajes enviados legítimamente, respuestas obtenidas, conversaciones sostenidas y próximos pasos acordados. Si no hay respuesta, no inventes interés. Si recibes un rechazo, respétalo y regístralo sin seguir escribiendo.

## Cómo usarlo con BuscaClientes
Explora primero, elige contactos relevantes y conserva notas/etapa en el CRM local. Descarga periódicamente tu CSV y resérvalo; no existe todavía sincronización cloud ni recuperación garantizada de un navegador perdido. La app no reemplaza tu evaluación ni el consentimiento apropiado para comunicaciones.
